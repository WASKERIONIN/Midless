Midless для Windows (x64)
=========================

Это сборка оригинального кода Midless (автор — Sirvoid), собранная из
репозитория без изменений в игровой логике.

Запуск
------
 game.exe    — игра. В главном меню:
                 * Singleplayer — запускает встроенный сервер и играет локально
                 * Multiplayer  — подключение к отдельному серверу (адрес/порт)
 server.exe  — выделенный сервер, порт 25565 (консольное окно с логом).
               Запускать только если нужен отдельный сервер для нескольких игроков.

Требования: Windows 10/11 x64, видеокарта с OpenGL 3.3.
Все библиотеки вшиты в exe, ничего дополнительно ставить не нужно.
Антивирус может ругаться на неподписанный exe — это нормально для самосборки.

Папки
-----
 textures\  — текстуры (terrain.png, humanoid.png, midless.png)
 mods\      — Lua-моды генерации мира. Сервер читает их из папки mods рядом с exe.
 world\     — создаётся автоматически при первом запуске: там seed.dat,
              worldgen.meta и сохранённые чанки (x.y.z.dat).

Управление
----------
 W A S D          — движение
 Space            — прыжок
 ЛКМ              — сломать блок
 ПКМ              — поставить блок
 Колесо мыши      — выбор блока
 T                — чат
 ESC              — меню
 Options          — дальность прорисовки (Draw Distance)

Важно про Draw Distance
-----------------------
 Сервер всё равно ограничивает дальность 8 чанками (serverWorld.maxDrawDistance),
 а по вертикали чанки грузятся только на +/-4 чанка (64 блока) — это ограничения
 оригинального кода, а не сборки. Значения больше 8 в ползунке расширяют только
 туман, поэтому на границе загрузки может быть виден резкий край мира.
