## Midless v42.1 — исправление «стены воды»

Те же `game.exe` / `server.exe` из релиза v42, в которых бинарно исправлена одна функция
генератора мира — `GetTerrainPoint()`: ниже уровня моря (y < 48) пещерный шум больше не
вырезает сухие карманы в грунте, поэтому вода не обрывается вертикальной стеной.
Всё остальное (текстуры, README v42, ReShade-optional) без изменений.

**Обязательно:** после запуска — **New World** (главное меню) или **Regenerate World** (пауза).
Правка действует только на новый рельеф; старая папка `world` со стеной не чинится.

Проверка: генератор пропатченных exe прогнан в эмуляторе x86-64 (Unicorn) — на сидах
1234 / 7 / 99991 в местах, где v42 давал 184 / 104 / 51 клеток «вода рядом с сухим воздухом»,
теперь 0 / 0 / 0; чанки совпадают байт в байт с нативной сборкой исправленного исходника.

Подробности, патч исходников и скрипты проверки: `tools/v42-water-wall/` в ветке `arena/01a07cc8-midless`.
