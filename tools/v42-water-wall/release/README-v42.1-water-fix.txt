Midless v42.1  (v42 + исправление "стены воды")
=================================================

Что это
-------
Это ТЕ ЖЕ САМЫЕ game.exe и server.exe из релиза v42, в которых бинарно
исправлена одна функция генератора мира - GetTerrainPoint().
Всё остальное (текстуры, README v42, ReShade-optional) без изменений.

Причина стены воды (доказано на исходниках Midless-src.rar и на
дизассемблере v42): пещерный 3D-шум вырезал "сухие" карманы в грунте
ниже уровня моря (y < 48). Вода ставится только в клетки открытого
воздуха, поэтому такие карманы оставались пустыми, а вода соседних
колонок обрывалась в них вертикальной стеной. Пункт 1 README v42
("исправлено и доказано") в сам exe v42 не попал - в бинарнике
GetTerrainPoint была без проверки уровня моря.

Исправление (эквивалент в C, server/src/world/worldgenerator.c):

    static int GetTerrainPoint(Vector3 p, float elevation) {
        if (p.y >= 16) { ... if (p.y + terrain >= 96 * elevation) return 0; }
    +   if (p.y < SEA_LEVEL) return 1;     // ниже уровня моря пещер нет
        float a = fnlGetNoise3D(&caveNoise, ...);
        ...
    }

Тот же патч в исходниках: tools/v42-water-wall/worldgenerator-no-caves-below-sea.patch
(ветка arena/01a07cc8-midless репозитория WASKERIONIN/Midless).

ВАЖНО: правка действует только на НОВЫЙ рельеф.
  * старые миры (папка world рядом с exe) не чинятся;
  * после запуска нажмите New World (главное меню) или Regenerate World
    (пауза) - папка world удаляется и мир генерируется заново.

Проверка
--------
Пропатченный код генератора прогнан в эмуляторе x86-64 (Unicorn) прямо из
этих exe - на сидах 1234 / 7 / 99991 в местах, где v42 давал 184 / 104 / 51
клеток "вода рядом с сухим воздухом", теперь 0 / 0 / 0, и 0 клеток сухого
воздуха ниже y=48. Результат совпадает с нативной сборкой исправленного
исходника байт в байт.

Что изменено в файлах (по 36 байт в каждом exe)
----------------------------------------------
  game.exe   GetTerrainPoint+0xEF : jmp -> вставка в хвосте .text (0x140161FB0)
  server.exe GetTerrainPoint+0xEF : jmp -> вставка в хвосте .text (0x1400AD630)
  вставка: comiss xmm6,[48.0f]; jb <return 1>; movss xmm8,[1.5f]; jmp back
  + VirtualSize секции .text расширен до SizeOfRawData, пересчитан CheckSum.
  Подписей у файлов не было и нет. Антивирус может ругаться так же, как
  и на любой самособранный exe.

Скрипт патча и проверка: tools/v42-water-wall/binpatch/ в репозитории.
